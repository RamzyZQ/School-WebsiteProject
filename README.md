## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Before deploying, set `NEXT_PUBLIC_SITE_URL` to the public website origin so Open Graph previews and structured data use the correct domain. Vercel deployments can use the automatically provided `VERCEL_URL`; for other hosts, configure `NEXT_PUBLIC_SITE_URL` in the hosting environment.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font/google`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to optimize and self-host DM Sans and DM Serif Display.
